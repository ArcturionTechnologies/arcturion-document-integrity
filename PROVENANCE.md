# Source and adaptation

This candidate derives from the first-party ArcturionDocuments `document-integrity` helper. The original verifier SHA-256 was `b15cf7628dd9efa305f2a558cf0e00495cce104d5d72f588cef2dc5eb01dfa24`; the original stop hook SHA-256 was `c51cc7d6c1a021ec8f746368133de5cd4e0cd030addc81c27a5eb557b5b3d42a`. The original skill and private runtime configuration are not redistributed here.

The verifier is adapted: it requires explicit required flags, checks empty/duplicate/missing map and plan entries, compares actual field names, and requires cited files to resolve under a supplied source root. This is an incompatible change to the original citation syntax. File existence is not source authentication or validation of a claim. The hook is redesigned for explicitly supplied roots, filters, optional host context, sidecars, report and event directories, an explicit lock and caller-supplied filing-receipt matching. Organization-specific filing integration, automatic lock clearing, private default paths and implicit configuration are not reproduced. The filing receipt is not authenticated. It must be configured deliberately and reviewed for its host. Tests and fixture generator use invented content.

The project is prepared from first-party Arcturion code; the bounded export records source hashes rather than a complete original development history. The MIT terms in LICENSE apply to original project material; dependencies retain their own notices. No private form, original runtime configuration, signature, media or personal record is included.
